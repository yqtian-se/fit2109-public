Week 12: Agentic Coding

Pre-reading · FIT2109 · Monash University

"The question is not whether AI will write code. It already does. The question is whether you understand what it wrote."

By the end of this week you should be able to

  1. Distinguish the key concepts: GenAI model, chatbot, coding agent, and CLI agent.
  2. Use GenAI APIs for narrow software tasks such as classification, extraction, and summarisation.
  3. Explain what AI agents can and cannot do reliably, including model limitations and common failure modes.
  4. Write effective prompts and project context files such as CLAUDE.md or AGENTS.md, and use a CLI coding agent such as Claude Code or Codex CLI to scaffold and refactor code with human oversight.
  5. Explain what MCP is and what an agent harness does — and use both to keep agent actions bounded and auditable.
  6. Evaluate agent outputs for correctness and security using diffs, tests, and edge-case checks before accepting them.
  7. Explain why strong coding knowledge is still required when AI tools are involved.

A scenario

You have an assignment due in two days. You paste a vague description of your task into an AI agent: "Rewrite this module to be more efficient." The agent works for three minutes, touching twelve files. The output looks clean — the code is well-formatted, uses modern idioms, even has type annotations. You accept all changes.

In a workshop discussion, your tutor asks you to walk through one function. You open the file. You recognise the function name, but not the body. The agent rewrote it using a framework you have never used before. Two of your original tests now pass for the wrong reasons — the function behaviour changed, but the tests were too shallow to catch it.

This scenario plays out more than you might expect. Week 12 asks you to practise the safe version of this workflow: use AI for a well-scoped task, then verify what it produced before you accept it. The pre-reading gives you the vocabulary and habits to do that safely. Pages 1–3 give the vocabulary (GenAI, GenAI APIs, agent capabilities, and chatbots versus agents); pages 4–7 give the habits (prompts, project context files, MCP, harness); pages 8–9 give the verification workflow and a workshop API demo. The final tools page gives concrete examples such as ChatGPT, Codex CLI, Claude Code, Gemini CLI, Cline, Aider, Copilot, and OpenClaw.

Central principle AI is a helper, not a replacement for engineering skill. It is useful only when you are strong enough to review, test, debug, and explain what it produced. Do not rely on AI for everything: use it where you can still own the result.
Concept check — before you start When someone says "AI tool", are they talking about a model, a GenAI API, a chatbot, a coding agent, or a command-line agent? Keep that distinction in mind as you work through this week's material.
