Week 12: Agentic Coding

Pre-reading · FIT2109 · Monash University

"The question is not whether AI will write code. It already does. The question is whether you understand what it wrote."

By the end of this week you should be able to

  1. Distinguish the key concepts: GenAI model, chatbot, coding agent, and CLI agent.
  2. Use GenAI APIs for narrow software tasks such as classification, extraction, and summarisation.
  3. Explain what AI agents can and cannot do reliably, including model limitations and common failure modes.
  4. Use a CLI coding agent with a focused task prompt, project instructions, and human review. Explain when a reusable skill would help.
  5. Explain how MCP connects agents to external tools and how the harness and permissions bound their actions.
  6. Evaluate agent outputs for correctness and security using diffs, tests, and edge-case checks before accepting them.
  7. Explain why strong coding knowledge is still required when AI tools are involved.
  8. Explain how AI affects bug reporting, open-source review, and website access, then decide which actions need human judgement.

A scenario

You are a developer maintaining a service that processes log files. A large file takes too long to process, so you ask a coding agent to improve the parser. The agent edits twelve files and adds a dependency. Its summary says the parser is faster, and the existing tests pass.

Before merging, a teammate asks which input sizes were measured and why the new dependency is needed. You inspect the diff and find that the agent also changed how malformed log lines are handled. The tests did not cover that behaviour. You now need to decide which changes solve the original performance problem and what evidence would justify keeping them.

Central principle You decide what problem the agent should solve, which actions it may take, and what evidence is enough to accept its work. Keep each delegated task small enough to review and explain.
Concept check — before you start When someone says "AI tool", are they talking about a model, a GenAI API, a chatbot, a coding agent, or a command-line agent? Keep that distinction in mind as you work through this week's material.
