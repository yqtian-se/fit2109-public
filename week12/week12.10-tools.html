Tool reference cards

ChatGPT
OpenAI's chat interface. Strong for explanation, planning, examples, and reviewing snippets when you provide the relevant context. Treat it as a conversational assistant unless you explicitly connect it to agentic tools.
GenAI APIs
Provider APIs let your own software call a model for narrow tasks such as classification, extraction, and summarisation. Use structured output, validate responses in code, and avoid sending data the task does not need.
Codex CLI
OpenAI's command-line coding agent. Runs from the terminal, works near Git and shell commands, and can use project instructions such as AGENTS.md to stay aligned with repository conventions.
Claude Code
Anthropic's official CLI agent. Run claude in any terminal. Full shell and file access. Reads CLAUDE.md automatically. Supports --allowedTools for scoping permissions. Useful for workshop demos where the diff can be reviewed carefully.
Gemini CLI
Google's open-source terminal agent for Gemini. Useful for repository exploration, file manipulation, command execution, dynamic troubleshooting, and automation from a command-line workflow.
Cline
Open-source VS Code extension. Model-agnostic — works with Claude, GPT-4, Gemini, and local models. Every file read and command run is shown in the extension panel before it executes, giving you fine-grained visibility and control.
Aider
Open-source CLI agent optimised for Git workflows. Automatically commits each set of changes with a descriptive message, making the agent's history visible and reversible via git log and git revert.
GitHub Copilot
Closed, subscription-based IDE integration. Provides inline code completions as you type, and a chat interface for larger tasks. The most widely deployed AI coding tool in industry. Available in VS Code, JetBrains, and other IDEs.
OpenClaw
A general autonomous-agent framework example rather than a FIT2109 coding recommendation. It is useful for thinking about persistent memory, messaging integrations, tool permissions, prompt injection, and why audit logs matter.
MCP (Model Context Protocol)
The open standard (Anthropic, 2024) for connecting agents to external tools and data sources. Not a tool itself — a protocol. Any MCP-compatible agent can use any MCP server: filesystem, GitHub, PostgreSQL, Slack, browser, and more. The ecosystem is growing rapidly.

Minimal Codex CLI workflow

For this workshop, students only need the safe local pattern. Start inside a Git repository, ask for a narrow change, review the diff, and run the tests yourself.

StepCommand or actionWhy it matters
Start in the projectcd my-project then git statusYou need to know the working tree state before letting an agent touch it.
Launch Codexcodex "Explain this repo structure"Good first task: read-only understanding before edits.
Ask for a scoped editcodex --sandbox workspace-write --ask-for-approval on-request "Add one test for the empty-input case. Do not change production code."The prompt constrains scope; sandbox and approvals constrain actions.
Review manuallygit diffThe agent's output is a proposal, not a decision.
Verifymake test or the project test commandTests are evidence; you still need to understand the changed code.
