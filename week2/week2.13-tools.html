Tool reference cards

shellcheck
Static analyser for Bash/sh scripts. Catches quoting bugs, unset variables, and bad practices before they bite you in production. Run locally (brew install shellcheck or apt install shellcheck) or paste scripts at shellcheck.net.
explainshell.com
Paste any shell command and see each flag and argument explained using the actual man page text. Essential for understanding commands you find on Stack Overflow before running them.
regex101.com
Interactive regex builder with real-time highlighting, match explanation, and multiple flavour support. Use it to develop and test patterns before embedding them in grep or find commands.
tldr
Example-first command references. Where man grep gives you every option, tldr grep gives you the five you will actually use. Install: npm install -g tldr or brew install tldr.
bash -x (trace mode)
Run bash -x script.sh to print each command after expansion, just before execution. Lines are prefixed with +. Invaluable for seeing exactly what the shell is doing — especially quoting and variable expansion problems.
ssh-keygen & ssh-agent
Generate keys with ssh-keygen -t ed25519. Load them into the agent with ssh-add ~/.ssh/id_ed25519 so you only need to enter the passphrase once per session. ssh-add -l lists loaded keys.
diff
Compares two files line by line. Exit status 0 = identical, 1 = differ — making it a natural pass/fail check in test scripts. Use diff -u for unified format (same as git diff). Combine with process substitution: diff expected.txt <(./script.sh).

Quick-reference: grep flags

$ grep -E 'WARN(ING)?' file       # extended regex
$ grep -Eo 'ERROR [0-9]+' file   # extract only matched text
$ grep -rn 'TODO' src/           # recursive, with line numbers
$ grep -q 'ERROR' file           # silent: exit status only
$ grep -v 'DEBUG' file           # invert: lines NOT matching
$ grep -c 'ERROR' file           # count of matching lines

Quick-reference: find predicates

$ find . -type f -name '*.py'
$ find . -type f -name '*.sh' ! -perm -u=x
$ find . -type f -newer ref.txt
$ find . -name '*.log' -exec wc -l {} +
$ find . -regextype posix-extended -regex '.*/[a-z]+-[0-9]{4}\.log'

Quick-reference: SSH workflow

$ ssh-keygen -t ed25519 -C "you@email.com"
$ ssh-copy-id -i ~/.ssh/id_ed25519.pub user@host
$ ssh user@host
$ ssh user@host 'cmd'
$ scp file.txt user@host:/remote/path/
$ scp user@host:/remote/file.txt .
