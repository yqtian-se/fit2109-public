5.8 Check Your Understanding

Quiz — 10 questions

These questions check concepts, not syntax recall. Think through each one before looking at the answer in class.

Question 1
What is the key difference between a local branch like main and a remote-tracking branch like origin/main?
Question 2
Which statement correctly distinguishes git fetch from git pull?
Question 3
What is the relationship between a branch and a pull request?
Question 4
Your feature branch has diverged from main and you run git rebase main. What happens to your feature branch's commits?
Question 5
Why is rebasing commits you have already pushed and shared considered risky?
Question 6
A merge has stopped with a conflict. You edit the file, remove the conflict markers, and run git add <file>. What have you just told Git?
Question 7
What question does git blame answer that git log does not directly answer?
Question 8
What problem is git bisect specifically designed to solve?
Question 9
A bad commit was merged into main three days ago and several teammates have already pulled it. What is the safer way to undo it?
Question 10
What is the difference between git reset --mixed HEAD~1 and git reset --hard HEAD~1?
