6.7 System Packages

Before you can install Python libraries or Node modules, you sometimes need OS-level tools — compilers, shared libraries, CLI utilities. System package managers handle this layer. The right one depends on the Linux distribution (or macOS).

Which package manager to use

Distro / OSPackage managerExample command
Ubuntu, Debian, WSL (Ubuntu)apt / apt-getsudo apt-get install curl
Red Hat, Fedora, CentOS, Amazon Linuxyum / dnfsudo dnf install curl
macOSbrew (Homebrew)brew install curl
Alpine Linux (common in Docker base images)apkapk add curl

apt / apt-get — Debian and Ubuntu

Most Docker base images (including ubuntu:22.04 and python:3.12-slim) use Debian/Ubuntu, so apt-get is what you will use inside Dockerfiles and in containers.

# Always update the package index before installing
$ sudo apt-get update
$ sudo apt-get install -y curl jq git   # -y: skip confirmation prompt
$ sudo apt-get upgrade                   # upgrade all installed packages to latest
$ sudo apt-get remove curl
$ apt-cache search json                 # search available packages
update vs upgrade apt-get update refreshes the local package index (the list of available packages and versions) — it does not install anything. apt-get upgrade then installs newer versions of any packages that already have upgrades available. Always run update before upgrade or install.

Using apt-get inside a Dockerfile

# Combine update + install in one RUN to avoid stale cache layer
RUN apt-get update && apt-get install -y \
    curl \
    jq \
    libpq-dev \
    && rm -rf /var/lib/apt/lists/*
# rm -rf /var/lib/apt/lists/*: delete the package index to shrink image

Using apt-get inside an interactive container

$ docker run --rm -it ubuntu:22.04 bash
# inside the container (running as root — no sudo needed):
root@container:/# apt-get update
root@container:/# apt-get install -y curl jq
root@container:/# curl -s https://httpbin.org/get | jq '.headers'
root@container:/# exit
# Everything installed is gone — the container is discarded on exit
Always run apt-get update first Package indexes inside container images are often outdated. Running apt-get install without apt-get update first may fail because the package is not in the cached index, even if it exists in the repository.
Try this Run docker run --rm -it ubuntu:22.04 bash. Inside, run curl --version — it will fail (not installed). Then install it with apt-get update && apt-get install -y curl and run curl --version again. Exit the container and verify curl is not affected on your host.
