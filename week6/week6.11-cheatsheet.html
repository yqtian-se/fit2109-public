Tool reference cards

docker
Container runtime and CLI. Key commands: pull, run, build, ps, rm, rmi, images. Use --rm for one-off containers and -it for interactive sessions.
Dockerfile
Plain-text build recipe. Key instructions: FROM, WORKDIR, COPY, RUN, ENV, CMD. Copy dependencies before source code to exploit layer caching.
apt-get
System package manager for Debian/Ubuntu. Always run apt-get update before install. Use -y to skip prompts. In Dockerfiles, combine both in one RUN instruction.
pip + venv
Python's package ecosystem. Create: python3 -m venv .venv. Activate: source .venv/bin/activate. Install: python3 -m pip install pkg (or pip3 install pkg — equivalent inside a venv). Lock: python3 -m pip freeze > requirements.txt. Deactivate: deactivate.
Other package managers
Same pattern everywhere: manifest + lockfile + install command. Node: npm / package-lock.json. Java: mvn / pom.xml. Rust: cargo / Cargo.lock. Ruby: bundle / Gemfile.lock. Go: go mod / go.sum.
Lockfiles (universal rule)
Always commit the lockfile. Never hand-edit it. Ignore the local packages directory (.venv/, node_modules/, etc.). The lockfile + install command fully reproduces the environment.
