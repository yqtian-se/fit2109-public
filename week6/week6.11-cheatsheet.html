Core Dockerfile instructions

InstructionPurpose
FROMSelect the base environment.
RUNExecute an installation or setup command during the build.
WORKDIRSet a stable internal path for later instructions and containers.
COPYPlace files from the build context into the image.
CMDChoose the default runtime command.

Distinctions to remember

  • Dockerfile: build recipe.
  • Image: reusable built contents and configuration.
  • Container: runtime instance created from an image.
  • venv: isolates Python packages; it does not provide a new OS or Python version.
  • --rm: remove the container after it exits; it does not remove the image.
  • Source change: rebuild the image before expecting the image to contain the changed file.
