Install and check Docker

Complete this setup before the Week 6 Applied class. The seminar explains the model; the Applied class runs the commands.

Windows students should already have an Ubuntu environment in WSL from Week 1. This page installs Docker; it does not reinstall WSL.

Windows: Docker Desktop with your existing WSL environment

  1. Install Docker Desktop for Windows.
  2. Use the WSL 2 backend. Start Docker Desktop and wait until it reports that Docker is running.
  3. Open Settings → Resources → WSL Integration. Enable the Ubuntu distribution used for FIT2109, then select Apply.
  4. Close and reopen the Ubuntu terminal. Run all FIT2109 Docker commands from that Ubuntu terminal.
Do not install a second Docker engine inside UbuntuWhen Docker Desktop provides WSL integration, do not run sudo apt install docker.io. Two Docker installations can refer to different engines, images, and containers.

Keep course projects in the Linux filesystem, such as ~/fit2109, rather than under /mnt/c/.... Docker builds are usually faster there.

macOS: Docker Desktop

  1. Install Docker Desktop for Mac.
  2. Choose Apple silicon if “About This Mac” shows an Apple chip; otherwise choose Intel.
  3. Start Docker Desktop, accept the requested permissions, and wait until Docker reports that it is running.

Native Ubuntu Linux: Docker Engine

This section is only for a computer that runs Ubuntu directly, not Ubuntu inside Windows WSL.

  1. Follow Docker's Ubuntu installation instructions.
  2. Complete the official Linux post-installation steps so course commands work without sudo.
  3. Log out and back in before running the readiness check.

Readiness check

Run these commands in the terminal that you will use for the Applied class:

docker version
docker run --rm python:3.12-slim python --version

The first image download may take several minutes. You are ready when:

  • docker version shows both a Client and a Server section; and
  • the second command exits successfully and prints a Python 3.12 version.

Common problems

ProblemWhat to check
docker: command not foundStart Docker Desktop, check WSL Integration on Windows, then reopen the terminal.
Cannot connect to the Docker daemonStart or restart Docker Desktop and wait for it to finish starting.
Permission deniedOn Windows, do not use sudo or change socket permissions. Check WSL Integration. On native Ubuntu, complete the official post-installation steps.
The image will not downloadKeep the complete error. Check the network, VPN, or proxy, then ask your tutor or IT support.
Bring evidence if setup failsCopy the complete output of docker version and the failing command. A tutor can diagnose an exact error more quickly than “Docker does not work.”
