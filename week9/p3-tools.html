Tool reference cards

time (shell built-in)
Measures real, user, and sys time for a whole command. Built into bash/zsh — no install needed. Use for whole-program baseline measurements.
timeit
Python standard library micro-benchmarker. Disables GC, runs many iterations, reports the best. Use: python3 -m timeit -s "setup" "expr". No install needed.
hyperfine
Statistical shell benchmarker. Reports mean ± std dev, min, max. Install: brew install hyperfine or download from GitHub. Use for comparing two programs end-to-end.
cProfile
Python built-in CPU profiler. No install needed. Run: python3 -m cProfile -s cumtime app.py. Sort by cumtime first to find the responsible function.
line_profiler / kernprof
Line-level CPU profiler. Install: pip install line_profiler. Add @profile to the hot function, run kernprof -l -v app.py. Look at the %Time column.
memory_profiler
Line-level memory profiler. Install: pip install memory_profiler. Add @profile to the function, run python3 -m memory_profiler app.py. Look at the Increment column.

The investigation ladder

  1. Benchmark — confirm the program is actually slow (time).
  2. Profile by function — find the hot function (cProfile -s cumtime).
  3. Profile by line — find the hot line (kernprof -l -v).
  4. Fix — apply one targeted change.
  5. Benchmark again — confirm the improvement is real (time or timeit).
  6. Run tests — confirm correctness is unchanged.
  7. Repeat or stop — if fast enough for the use case, stop.
