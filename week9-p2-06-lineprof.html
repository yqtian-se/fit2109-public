9.6 line_profiler: Which Line Is the Bottleneck?

cProfile tells you the function is slow. line_profiler tells you the exact line inside that function that is doing the work. Together, these two tools give you a precise fix target without having to guess.

Installation and setup

$ pip install line_profiler

Add the @profile decorator to the function you want to inspect. You do not import anything — kernprof injects the decorator at run time:

# hot.py
@profile                          # no import needed -- kernprof injects this
def build_result(items):
    result = ""
    for item in items:
        result += str(item)       # repeated string concatenation
        processed = result.strip()
    return processed

Running kernprof

# -l  writes line-level stats  -v  prints them immediately
$ kernprof -l -v hot.py

Reading the output

Total time: 0.011124 s
File: hot.py
Function: build_result at line 2

Line   Hits    Time(µs)  Per Hit   %Time   Contents
   3   1001      312.0     0.3      2.8   for item in items:
   4   1000    9876.0     9.9     88.7   result += str(item)
   5   1000     936.0     0.9      8.4   processed = result.strip()
   6      1       0.1     0.1      0.0   return processed

Line 4 consumes 88.7% of the function's time. That is the line to fix. Everything else is noise — don't touch it.

%Time is the key column Absolute time (µs) varies with machine speed and input size. %Time is stable: it tells you the fraction of the function's total cost attributable to each line. Focus on lines with high %Time — those are the ones worth fixing.

The two-step investigation pattern

  1. Step 1 — cProfile: python3 -m cProfile -s cumtime app.py → find the slow function.
  2. Step 2 — line_profiler: add @profile to that function, run kernprof -l -v app.py → find the slow line.

These two steps together take under two minutes and give you a precise target. Without them, you are guessing.

Remove @profile before committing @profile is injected by kernprof at runtime. If you run the script normally (without kernprof), Python will raise NameError: name 'profile' is not defined. Remove the decorator before committing or shipping.
