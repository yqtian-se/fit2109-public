Common traps at a glance

TrapSymptomFix
uniq without sortMany counts of 1sort first
sort without -n10 before 9sort -n
Splitting quoted CSV on commasNames cut in half, silently wrong totalsMiller / SQLite / CSV library
grep matching substringsCounts too highTest the field with awk
Greedy .*Substitution swallows too much[^X]* instead
sed prints non-matching linesUnrelated lines in extracted outputsed -n with p
Imported SQLite columns are TEXTWrong sort orderCAST, or define column types
Missing JSON keynull values; objects silently droppedCheck with has() / //
Pipeline hides an early failureEmpty report, exit status 0set -o pipefail
Wrong grouping keyEvery count is 1Group on the thing you want to count
The rule of thumb Inspect first. Pick the tool that matches the data's shape (lines, table, tree). Build the pipeline one stage at a time, checking each. When the structure outgrows the tool — quoting in CSV, nesting in JSON, grouping across columns — switch tools early.
