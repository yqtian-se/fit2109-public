3.17 Cheat Sheet: Editor Shortcuts Worth Remembering

A quick reference for the two editors covered this week. Bookmark this page — you'll want it again in Weeks 4–12 when you're editing rather than reading about editing.

Vim: minimum survival set

Open a file:         vim file.txt
Insert text:         i
Append text:         a
Open new line:       o
Return to Normal:    Esc
Move:                h j k l
By words:            w b e
Line start/end:      0   $
Delete:              x   dd   dw
Copy and paste:      yy   p
Undo / Redo:         u   Ctrl-r
Search:              /pattern   n
Save / quit:         :w   :q   :wq   :q!

VS Code: the shortcuts you'll use constantly

Quick Open
Jump to any file by typing its name, instead of clicking through the Explorer. The fastest way to move around a large project.
Command Palette
Search for and run any editor command by name — "Format Document," "Organize Imports," "Toggle Terminal" — without memorising a shortcut for each one.
Go to Definition
Jump from a function call straight to where it's defined. Depends on language support being installed (3.9).
Find in Files
Search a whole workspace, not just the open file. Often the fastest way to start understanding an unfamiliar codebase (3.10, 3.16).
Split Editor
Open a second file beside the first. Use it to compare a definition against a call site, or a test against the code it tests (3.12).
Multi-cursor / Select All Occurrences
Place a cursor on every occurrence of a word in view, then edit them all at once — with every affected location visible before you type (3.12).
Rename Symbol
A language-aware rename that updates every reference, not just text matches. Safer than search-and-replace for renaming a function or variable (3.13).
Toggle Breakpoint
Click the gutter next to a line number to pause execution there when running under the debugger (3.14).
One habit worth building now Whenever you catch yourself repeating the same three or four clicks, open the Command Palette and search for what you're trying to do. There is very likely already a command — and often a shortcut — for it.
