Week 1: Introduction to the Shell

Pre-reading · FIT2109 · Monash University

By the end of this week you should be able to

  1. Explain what a shell is and why it exists alongside a GUI.
  2. Navigate the filesystem using absolute and relative paths.
  3. Create, copy, move, and remove files from the command line.
  4. Read and change file permissions.
  5. Explain how $PATH controls which programs the shell can find and run.
  6. Connect commands together using pipes and redirection.

A scenario

You are setting up a new project on a shared Linux server. There is no desktop, no file manager, no right-click menu — just a terminal prompt. You need to create a folder structure, copy some configuration files, make a script executable, and check that a pipeline of commands produces the right output before you leave it running overnight.

Everything you need to do that confidently is in this week's pre-reading. The shell is not a relic — it is the control surface that sits underneath every modern development workflow, from CI pipelines to cloud deployments to container orchestration. Learning it now means every tool you encounter later will make more sense.

Concept check — before you start When you double-click a program to run it, what actually happens between the click and the program appearing on screen? As you read, build a mental model of where the shell fits in that chain.
