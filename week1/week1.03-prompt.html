2.2 The Terminal Prompt

When you open a terminal, the first thing you see is the prompt. It is not just decoration — it carries useful information. Here is a typical prompt:

The prompt character is usually $ for a regular user and # for the root (administrator) user. You will never type the $ — it is just a visual marker that the shell is waiting for your input.
