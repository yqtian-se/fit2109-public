0.1 Before you start

0.2 Make file extensions and hidden files visible

You will be working with files such as check_progress.sh and hidden dot-files. Turn these on so nothing is invisible to you.

▦ Windows 11

  1. Open File Explorer.
  2. Click View → Show.
  3. Tick File name extensions.
  4. Tick Hidden items.

 macOS

  1. Open Finder.
  2. Menu bar: Finder → Settings.
  3. Choose the Advanced tab.
  4. Tick Show all filename extensions.
  5. Hidden files: press ⌘ ⇧ . in any Finder window.

0.3 Open a Linux shell

This unit is about the Linux shell, so you need one. Pick whichever applies to you.

▦ Windows

Important: PowerShell and Command Prompt are not Linux shells and cannot run our bash scripts. Use one of these instead:

  • Easiest — no install: use the Ed workspace terminal in your browser. Every “Try this in Ed” in the reading runs there.
  • On your laptop: install WSL (Ubuntu). Open PowerShell as Administrator, run the command below, then restart and set a username and password.
PowerShell (Administrator)
> wsl --installInstalling: Ubuntu ...Restart your computer to finish.

Afterwards, open Ubuntu from the Start menu to get your shell.

 macOS

macOS already ships with a shell — you do not need to install anything.

  • Press ⌘ Space, type Terminal, press Return.
  • You will see a prompt ending in % or $. That is the shell.
  • Or use the Ed workspace terminal in your browser.

0.5 It is not working — HELP!

These four errors stop most people. Find your error message and apply the fix.

What you seeWhat it means and how to fix it
bash: check_progress.sh:
No such file or directory		 You are in the wrong folder. Run pwd — it must end in /week1-rescue. If not, run cd ~/fit2109/week1-rescue. Then run ls and check you can see check_progress.sh.
unzip: command not found WSL / Ubuntu: run sudo apt update && sudo apt install unzip. Mac: unzip is built in — if you see this, you are probably not in a Linux shell.
bash: command not found
(on Windows)		 You are in PowerShell or Command Prompt, not Linux. Open Ubuntu (WSL) from the Start menu, or use the Ed workspace terminal. Windows' own shells cannot run bash scripts.
Permission denied You do not need this for check_progress.sh (it runs via bash file). For a script you run as ./script.sh, add the execute bit first: chmod u+x script.sh — Task 3 of the applied class covers exactly this.
