1.7 Working Directory and File Manipulation

The working directory is where the shell is currently located. Every command that involves a file uses the working directory as the starting point unless you give an absolute path.

The core file manipulation commands:

bash
# See where you are and what's here
$ pwd                          # print working directory
$ ls -la                       # list all files with details

# Create
$ mkdir week1                  # make a directory
$ touch notes.txt              # create an empty file

# Copy, move, remove
$ cp notes.txt backup.txt      # copy a file
$ mv notes.txt summary.txt    # rename/move a file
$ rm backup.txt               # delete a file (no undo!)
Caution rm does not move files to a Trash folder — it deletes them immediately. There is no undo. Always double-check the path before running rm.

Matching multiple files with globs

You will often want to act on a group of files at once. The shell provides glob patterns (also called wildcards) — special characters that the shell expands into a list of matching filenames before the command runs.

PatternMatchesExample
*Any string of characters (zero or more)*.txt — all .txt files
?Exactly one characterlog?.txt — log1.txt, log2.txt, …
[abc]One character from the setreport[12].txt — report1.txt or report2.txt
bash
# List only .txt files
$ ls *.txt

# Copy all .log files into a backup directory
$ cp *.log backup/

# Remove all .tmp files (careful — no undo!)
$ rm *.tmp
The shell expands globs, not the command When you type ls *.txt, the shell replaces *.txt with the list of matching filenames before ls even starts. ls never sees the * — it receives a list of individual filenames. This distinction matters and is covered in depth in the Week 2 pre-reading.

Reading ls -la output is one of the most useful shell skills. Each line looks like this:

drwxr-xr-x  3 student staff  96 May 20 10:15 week1
-rw-r--r--  1 student staff 142 May 20 10:12 notes.txt

The columns mean: type+permissions, link count, owner, group, size, date, name. The first character is d for directory, - for file, l for symbolic link.
