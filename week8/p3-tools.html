Tool reference cards

pylint
Python linter with a score out of 10. Install: pip install pylint. Run: pylint script.py. Fix E (error) codes first.
flake8
Lightweight PEP 8 checker. Install: pip install flake8. Run: flake8 script.py. Fast enough to run on every save.
mypy
Static type checker for Python. Install: pip install mypy. Run: mypy script.py. Requires type annotations to be most useful.
shellcheck
Bash/sh linter. Often pre-installed; otherwise brew install shellcheck or apt install shellcheck. Run: shellcheck script.sh.
GDB
GNU Debugger for C/C++ on Linux. Compile with -g. Key commands: break, run, next, step, print, backtrace.
LLDB
Part of the LLVM project. Default debugger on macOS; also available on Linux wherever LLVM is installed. Same workflow as GDB with slightly different syntax (p instead of print, bt instead of backtrace).
Perses
Automated program reducer. Needs Java. Download JAR from GitHub releases. Write a test script (exit 0 = bug present), then run Perses on the large file.
git bisect
Binary search over commit history to find the commit that introduced a bug. git bisect start → mark good/bad commits → Git checks out the midpoint each time.
